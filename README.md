# Toss
### A satisfying, physically accurate 3D coin toss web app.

## 🛠️ Tech Stack
* **Core:** HTML5, CSS3, JavaScript (ES6+)
* **3D Engine:** [Three.js](https://threejs.org/) (WebGL rendering)
* **Physics:** [Rapier.js](https://rapier.rs/)
* **Animation:** [GSAP](https://gsap.com/)
* **Post-Processing:** [EffectComposer](https://threejs.org/docs/#EffectComposer)
* **Build Tool:** [Vite](https://vite.dev/)
